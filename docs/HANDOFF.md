# 交接說明（給接手的 Claude 對話）

## 專案與使用者決定

- 目標：個人用的「台海情勢觀測」網站，自動抓取可信的公開資料，算出暫定的綜合緊張指數。
- 使用者決定：只給自己看；只做繁體中文；全自動抓資料；主要交給 Claude 做；全部用免費方案；repo 維持公開（所以用 GitHub Pages + GitHub Actions）。
- **工作規則（使用者要求）：每一步動手前，先報告規劃並詢問有無不足，等使用者確認後再繼續。** 一律用繁體中文溝通。
- 不要主動開 PR，除非使用者明確要求。開發分支：`claude/gallant-heisenberg-uxyg55`。

## 目前完成（第 1 階段）

- `scripts/`：Python 標準函式庫寫成，不需安裝套件。
  - `fetch_mnd.py` 國防部每日「臺海周邊海、空域動態」（`--backfill` 回補、`--reparse` 不連網重新解析）
  - `fetch_market.py` 證交所加權指數（逐月、可續抓）＋ FRED 新台幣匯率
  - `fetch_news.py` Google 新聞 RSS 關鍵字每日報導數（共機、共艦、軍演、圍台、封鎖、制裁、統戰、國台辦）＋中央社標題
  - `build_site_data.py` 整合資料、算暫定分數，輸出 `site/data/dashboard.json`
  - `common.py` 共用抓取（含重試）、狀態記錄 `data/status.json`
- `site/index.html`：靜態儀表板（Chart.js 4.4.1，從 cdnjs 載入），讀 `site/data/dashboard.json`。
- 資料已回補：國防部 2,048 篇（2020-09 起）、加權指數 1,512 日、匯率 1,548 日、新聞 90 天。
- 暫定評分：各指標與過去 365 天比較的百分位，軍事／市場／新聞三面向等權平均。正式模型是第 3 階段。

## 已知限制與踩過的坑（請務必注意）

1. **國防部 2024-01 至 2025-02 的公告只有圖片、沒有文字**，無法解析，圖表顯示為空白（網頁已說明）。
2. **User-Agent 衝突**：FRED 會拒絕瀏覽器樣式的 UA，國防部會拒絕自訂名稱；Python 預設 UA 兩者都接受，所以 `common.py` 不自訂 UA。
3. **證交所會封鎖頻繁請求**（連續請求後一段時間內全部失敗）。`fetch_market.py` 已放慢（每月間隔 10 秒）、由新到舊抓、可續抓。
4. **陸委會網站、臺灣銀行牌告匯率有 Cloudflare 機器人驗證**，抓不到，已改用其他來源。GDELT 常回 429，暫不採用。
5. 國防部偶爾回 403，重試即可通過；`fetch_mnd.py` 已含重試與少量併發。
6. 新聞熱度只能回補約 90 天；中央社 RSS 每次只有最新約 20 則，所以每天要抓並累積。
7. 這些測試是在雲端開發環境做的，**GitHub Actions 的網路位置不同，國防部與證交所可能封鎖它**，上線後務必驗證。
8. 目前 Artifact 預覽（私人）：https://claude.ai/artifact/WzZWAoueF5gPVVXDaazDs7 （僅供預覽，正式網站走 GitHub Pages）。
