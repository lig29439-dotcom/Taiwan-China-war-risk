## 備註

- 測試是在雲端開發環境進行；正式自動排程會在 GitHub Actions 執行，IP 不同，上線前需再驗證一次（尤其國防部與 GDELT）。
- 國防部網站改版時解析程式可能失效，需加入「解析失敗時發出警示」的機制。
